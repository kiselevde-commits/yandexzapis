# Контекст проекта: TG-Бот бронирования слотов для Олимпиадной Математики

Ты — AI-инженер в среде Zoo Code. Мы создаем асинхронного Telegram-бота для записи учеников на математические отслушки с динамическим скрытием слотов и синхронизацией с локальным файлом Excel. Клиент — начинающий разработчик, пиши код с подробными комментариями на русском языке.

## Технологический стек
- Python 3.10+
- aiogram 3.x (СТРОГО 3.x, используем Router, InlineKeyboardBuilder, StatesGroup и Filter)
- openpyxl (для чтения и записи локального файла Excel формата .xlsx)

## Хранилище данных (локальный Excel)
- Вместо Google Таблиц используем локальный файл Excel на компьютере: `slots.xlsx`.
- Путь к файлу задаётся переменной `EXCEL_FILE` в `config.py`.
- Данные хранятся на листе с названием `Слоты` (переменная `EXCEL_SHEET_NAME`).
- Ожидаемые колонки листа `Слоты`:
  - `Дата` — дата занятия.
  - `Время` — время слота.
  - `Статус` — состояние слота: `Свободно` или `Занято`.
  - `Студент` — никнейм ученика, который записался (пусто, если слот свободен).
- Работа с файлом организована так, что при изменении данных файл полностью пересохраняется через `wb.save()`.

## Правила архитектуры
- Проект должен быть модульным:
  - `config.py` — токены, путь к файлу Excel и прочая конфигурация.
  - `excel_engine.py` — чтение и запись локального файла Excel через openpyxl.
  - `keyboards.py` — генерация динамических инлайн-кнопок (даты и слоты времени).
  - `handlers.py` — обработка команд, состояний (FSM) и нажатий на кнопки.
  - `bot.py` — точка входа и запуск polling.
- Логика работы с Excel вынесена в `excel_engine.py` и предоставляет три функции:
  - `get_free_dates()` — список уникальных дат со свободными слотами.
  - `get_free_slots_for_date(date)` — список свободных слотов времени на дату.
  - `book_slot(date, time, nickname)` — бронирование слота; возвращает `True` при успехе и `False`, если слот уже занят.
